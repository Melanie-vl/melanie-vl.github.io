# Portfolio – Melanie van Leeuwen

Persoonlijke portfoliowebsite (één pagina, HTML + CSS, geen build-stap nodig).

## Tekst aanpassen
Alle teksten staan in `index.html`. Zoek op `TODO` voor de plekken die nog aangevuld moeten worden
(kunsttraject en Parksessies 2026).

## Foto's toevoegen
Zet een foto in de map `images/` en voeg in `index.html` binnen een `<div class="gallery">` een regel toe:

    <button><img src="images/bestandsnaam.jpg" alt="Korte beschrijving van de foto" loading="lazy"></button>

Gebruik `class="wide"` op de button voor een brede foto.

## Online zetten
De site draait via GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
